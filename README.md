# 天启之路 · The Road of Apocalypse

竖屏移动肉鸽小游戏（微信小游戏为目标平台，当前为网页可玩原型）。

控制"天选者"走位，自动战斗清理怪群，升级时三选一"天启之力"构筑流派，击败最终怪物通关。

## 在线试玩

启用 GitHub Pages 后访问：`https://<用户名>.github.io/The-Road-of-Apocalypse/`

（手机、电脑浏览器均可，微信内直接打开）

## 本地运行

- 方式一：直接双击 `index.html`（纯静态页面，无需服务器）
- 方式二：`node server.js` 后访问 `http://127.0.0.1:8123`

## 当前版本：v0.1 占位框架原型

全部美术为色块+文字占位、数值为占位值，用于验证玩法手感。

### 三姿态 × 六流派

| 姿态 | 流派 | 体验 |
|---|---|---|
| 战士 | 漂泊剑客 | 近战挥砍 + 远程穿透剑气（回锋/行迹/巨型断空） |
| 战士 | 重骑士 | 护盾减伤换血（盾撞/反震/盾破冲击） |
| 射手 | 逐风射手 | 远程高机动（移动叠攻速/分流箭/风行爆发） |
| 射手 | 短铳射手 | 扇形泼射流弹"双响—装填"节奏（贴脸高风险高伤） |
| 法师 | 坠星法师 | 敌群密集处延迟陨石（碎星/连星/巨型陨星） |
| 法师 | 巫师 | 中毒控场（易伤/减速冰冻/蛊惑反水/周期毒爆） |

### 天启之力（42张占位卡池）

- 首次三选一必出本姿态两个流派核心，二选一定流派
- 成长卡重复选择升星（最高三星），终极进化在核心三星+两张二星成长后解锁
- 卡面：名称/流派/类型/星级/当前效果/下一星变化

## 操作

- 手机：拖动屏幕移动（虚拟摇杆）
- 电脑：WASD / 方向键移动，Esc/P 暂停

## 调试工具（正式版移除）

画面右侧"调试"悬浮球：倍速（1/2/4/8）、升级、无敌、召唤怪物、清屏等。
URL 参数：`?fast=8` 加速、`?pose=mage` 指定初始姿态。

## 技术

纯前端 HTML5 Canvas + 原生 JS，无框架无依赖，`js/` 下按 config / cards / entities / world / main 分层。
