# 天启之路 · The Road of Apocalypse

竖屏移动肉鸽小游戏（微信小游戏为目标平台，当前为网页可玩原型）。

控制"天选者"走位，自动战斗清理怪群，升级时三选一"天启之力"构筑流派，击败最终怪物通关。

## 在线试玩

部署成功后访问：<https://jiangtt135563-droid.github.io/The-Road-of-Apocalypse/>

（手机、电脑浏览器均可，微信内直接打开）

## 本地运行

- 方式一：直接双击 `index.html`（纯静态页面，无需服务器）
- 方式二：`node server.js` 后访问 `http://127.0.0.1:8123`

## 当前版本：v0.2.10（最新）

- **角色动画**：主角立绘带程序化动画——移动步伐起伏与行走摆动、待机呼吸、攻击向目标突进+前倾+挥击弧光；选定流派核心时播放**变身过渡**（光束自天而降扫落 → 角色从光中显现 → 白闪弹出，变身期间短暂保护）
- **摄像机大地图**：关卡地图 2200×2200，主角基本锁定屏幕中心（手指不挡角色），大多数时候是地图在动；地图有可见边界
- **4 张主题地图 × 各 3 关**：草原 → 雪原 → 沙漠 → 地狱，怪物血量/伤害随地图与关卡成长，胜利后可"下一关"直通
- **月牙剑气**：漂泊剑客的剑气为单月牙形（参考月牙天冲），凹面朝施放者
- **HUD**：最终怪物血条并入状态栏堆叠，不再遮挡经验条
- **天启之力规则**：一关最多选15次（第1次双核心定流派 + 成长/通用相对随机穿插，满星移出卡池）；集齐三张三星成长卡后，第16次升级解锁**奥义专属选择**（仅一张紫色奥义卡）
- **卡面**：卡名以 +/++ 表示二/三星；特化卡按星级配色（1星绿/2星蓝/3星黄），奥义紫、通用灰
- **暂停回看**：已选天启之力芯片可点击查看具体效果
- **逐风射手（激光射手）**：连射叠层越射越快（每层+4%攻速），叠满箭矢光矢化；终极"光矢无踪"进入光矢形态——攻速×4、移速×1.4、倾泻贯穿光矢（受伤缩短持续时间）
- **锁头操作**：战斗中第二指按住屏幕（电脑：按住鼠标左/右键）= 优先攻击范围内最高级目标（Boss>精英>小怪）

### 三姿态 × 六流派

| 姿态 | 流派 | 体验 |
|---|---|---|
| 战士 | 漂泊剑客 | 近战挥砍 + 远程穿透剑气（回锋/行迹/巨型断空） |
| 战士 | 重骑士 | 护盾减伤换血（盾撞/反震/盾破冲击） |
| 射手 | 逐风射手 | 远程高机动（连射叠攻速/分流箭/光矢形态） |
| 射手 | 短铳射手 | 扇形泼射流弹"双响—装填"节奏（贴脸高风险高伤） |
| 法师 | 坠星法师 | 敌群密集处延迟陨石（碎星/连星/巨型陨星） |
| 法师 | 巫师 | 中毒控场（易伤/减速冰冻/蛊惑反水/周期毒爆） |

## 操作

- 手机：拖动屏幕移动（虚拟摇杆）
- 电脑：WASD / 方向键移动，Esc/P 暂停

## 调试工具（正式版移除）

画面右侧"调试"悬浮球：倍速（1/2/4/8）、升级、无敌、召唤怪物、清屏等。
URL 参数：`?fast=8` 加速、`?pose=mage` 指定初始姿态。

## 技术

纯前端 HTML5 Canvas + 原生 JS，无框架无依赖，`js/` 下按 config / cards / entities / world / main 分层。
